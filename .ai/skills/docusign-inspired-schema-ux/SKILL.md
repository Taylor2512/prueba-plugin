# SKILL — UX de schemas inspirada en DocuSign/Wix

## Cuándo usar

Cuando se refine el diseño de campos en canvas.

## Pasos

1. Separar patrón funcional de marca.
2. Diseñar idle/hover/selected/group.
3. Mantener PDF protagonista.
4. Usar tokens scoped.
5. Validar con Playwright.

## No hacer

No copiar CSS/branding. No usar CSS para arreglar geometría.

## Validación

Build/lint y screenshot/regresión visual.
