# PRT-100 — Deterministic snapshot, Viewer and PDF roundtrip

## Objective

Prove committed canonical values survive snapshot/restore and produce deterministic
Viewer/PDF output without mutable remote refetch by default.

## Product boundary

SISAD-PDFME reusable. No concrete consumer business semantics.

## Acceptance

- semantic equality after restore;
- Viewer is read-only;
- PDF output uses committed values;
- explicit preflight failure for unsupported rendering capability.

## Required process

1. reconcile live source/evidence/task dependencies;
2. characterize first divergence;
3. implement the smallest correct authority;
4. execute focal/integration/browser gates appropriate to risk;
5. write evidence;
6. update status only from executed facts.

## Safety

No destructive Git. No blanket stash. No force push. No worktrees for this project.
One writer per overlapping file set. Only the integrator stages/commits/pushes.
