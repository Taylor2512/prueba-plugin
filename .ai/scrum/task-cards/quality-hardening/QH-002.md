# QH-002 — Repetibilidad de los fallos de grupos

## Objetivo

Caracterizar checkbox parity y radio isolation sin ejecutar toda la suite.

## Ejecución

```bash
npx playwright test tests/e2e/designer/grupos-opciones.spec.ts --project=chromium --workers=1 -g "checkboxGroup — declarativo y arrastrado" --repeat-each=10 --trace=retain-on-failure
npx playwright test tests/e2e/designer/grupos-opciones.spec.ts --project=chromium --workers=1 -g "radioGroup — dos grupos arrastrados" --repeat-each=10 --trace=retain-on-failure
```

## Clasificación

- 10/10 mismo fallo: contrato/assertion o bug determinista.
- 1–9 fallos: timing, locator, placement o contaminación.
- 0 fallos aislado: contaminación entre tests.

## DoD

Cada resultado tiene evidencia, trace si falla y una decisión explícita.

## Evidencia ejecutada — 2026-08-18

Ambos comandos de caracterización ejecutados tal cual los declara la tarjeta:

- `-g "checkboxGroup — declarativo y arrastrado" --repeat-each=10` → **10/10 PASS**
- `-g "radioGroup — dos grupos arrastrados" --repeat-each=10` → **10/10 PASS**

Resultado: **0 fallos**. La tabla de clasificación de esta tarjeta asigna "0
fallos aislado" a contaminación entre tests, pero la suite completa
(`tests/e2e/designer`, 68/68) también pasa, así que tampoco hay contaminación
cruzada.

**Decisión explícita**: la premisa de esta tarjeta —"los dos fallos actuales"—
ya no se sostiene. Los fallos que QH-001/QH-002 se escribieron para diagnosticar
fueron eliminados por el fix de identidad de option groups del commit
`addb4ef9` (omitir claves de identidad `undefined` en
`buildOptionGroupDefaultSchema` y asignar `id` DESPUÉS del spread en
`Designer.addSchema`). No hay bug determinista, ni timing, ni contaminación que
corregir.

El valor de regresión se conserva vía QH-001: el diagnóstico mejorado clasifica
el modo de fallo si vuelve a aparecer, verificado reintroduciendo el bug a
propósito.
