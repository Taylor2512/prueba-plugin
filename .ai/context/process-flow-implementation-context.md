# Contexto — Implementación por proceso y cierre de faltantes

## Objetivo

Convertir faltantes en tareas por proceso, no por archivo suelto.

## Plantilla de proceso

```md
# Proceso

## Objetivo
## Componentes involucrados
## Fuente de verdad
## Estados válidos
## Estados inválidos
## Datos preservados
## Comandos permitidos
## Tests unitarios
## Tests Playwright
## Criterio de aceptación
```

## Prioridad de cierre

1. Selection state machine + shortcuts + command bus.
2. Standard schemas + groups + no-overlap.
3. Snapshot + Form/Viewer/Generator.
4. DetailView/ListView.
5. CSS y diseño visual.
