# TRC-021 — Exhaustive snapshot semantic round-trip

## Objective

Validate create -> mutate -> snapshot -> stringify -> parse -> restore semantic parity.

## Coverage set

text, 0, false, [], radio, checkbox group, date, signature refs, attachment refs, comments, readOnly, positionLocked, users, documents, assignments, multi-user, multi-document.

## Acceptance

- semantic equivalence comparator defined (ignores ephemeral fields);
- round-trip passes for canonical fixture and targeted edge fixtures;
- failures include entity path and field-level diff hints.

## Safety

No deep-equality dependence on transient runtime state.
