# TRC-043 — Canonical full reference JSON fixture

## Objective

Create one canonical fixture that exercises core portable contract surface comprehensively.

## Minimum content

3 users, 2 documents, multiple schema families, single/shared assignments, readOnly, positionLocked, radioGroup, checkboxGroup, text, number=0, checkbox=false, signature, comment.

## Acceptance

- fixture reused across serialize/deserialize/Designer/Form/Viewer/Snapshot/PDF tests;
- fixture documented as authoritative reference payload;
- fixture evolution policy prevents ad-hoc duplicates.

## Safety

No parallel near-duplicate mega fixtures.
