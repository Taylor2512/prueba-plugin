# Prompt Engineering Skill

## Propósito
Crear prompts ejecutables.

## Cuándo usar
Inicio de agente.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Identidad.
2. Objetivo/límites.
3. Comandos focales.
4. Parada/handoff.
5. Excluir auditoría.
6. Revisar ambigüedad.

## Validaciones
No contradice START.

## Anti-patrones
Copiar todo el plan.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
