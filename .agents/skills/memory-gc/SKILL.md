# memory-gc

## Workflow

1. Leer task y route.
2. Formular una sola pregunta.
3. Consultar índices/catálogos por ID o texto.
4. Producir evidence packet.
5. Aplicar o recomendar cambio mínimo.
6. Registrar trace y memory delta.
