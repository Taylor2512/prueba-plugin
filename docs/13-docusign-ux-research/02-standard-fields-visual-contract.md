# Contrato visual de schemas estándar

| Schema | Idle | Selected | DetailView |
|---|---|---|---|
| Text | caja ligera, fondo sutil | borde 1.5px + handles | contenido, estilo, validación |
| Number | igual texto + indicio numérico | borde owner | min/max/formato |
| Checkbox | cuadrado compacto | borde owner fuerte | checked/required |
| CheckboxGroup | borde punteado + filas | group selected + `+` | opciones/min/max |
| RadioGroup | borde punteado + radios | opción/group selected | options/default |
| Select | caja con chevron | borde owner | options/default/placeholder |
| Signature | línea/caja limpia | handles | proveedor/label/required |
| Image/SVG | preview moderado | handles | asset/fit |
| Barcode/QR | preview compacto | handles | value/type |
| Table | tamaño inicial moderado | handles | columns/rows |
