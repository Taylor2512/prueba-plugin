# Acceptance gates

## Gate funcional

- [ ] Proceso cubierto por contrato.
- [ ] Datos críticos preservados.
- [ ] No se rompe flujo paralelo.

## Gate interacción

- [ ] Selección simple/múltiple.
- [ ] Moveable/Selecto.
- [ ] Shortcuts.
- [ ] Toolbar.

## Gate persistencia

- [ ] Snapshot round-trip.
- [ ] Form/Viewer/Generator.

## Gate visual

- [ ] PDF protagonista.
- [ ] Schemas ligeros.
- [ ] No overlap.
- [ ] Multi-page estable.

## Gate IA

- [ ] Docs actualizadas.
- [ ] Contexto/regla/prompt ajustados si cambia contrato.
