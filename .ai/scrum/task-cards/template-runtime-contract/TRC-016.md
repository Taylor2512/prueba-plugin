# TRC-016 — Explicit config precedence contract

## Objective

Make precedence deterministic and testable across safety constraints, surfaces, template settings and schema properties.

## Candidate precedence

hard safety constraint > surface override > instance configuration > template setting > schema property > default

## Acceptance

- precedence source-of-truth defined in one module;
- unit matrix covers Viewer/Form/Designer and capability-disabled cases;
- diagnostics include effective origin for denied actions when possible.

## Evidence requirements

- table-driven tests for precedence outcomes;
- at least one integration test per surface.

## Safety

No implicit precedence in scattered conditionals.
