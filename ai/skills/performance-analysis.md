# Performance Analysis

## Propósito

Medir y mejorar hotspots.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Definir métrica.
2. Medir.
3. Localizar.
4. Optimizar.
5. Comparar.
6. Documentar.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No optimizar sin medir.

## Salida

```md
## Alcance
## Evidencia
## Procedimiento aplicado
## Resultado
## Riesgos
## Dependencias
```
