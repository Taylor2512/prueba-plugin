# Instrucciones para completar lo faltante

1. No empezar por CSS.
2. Ejecutar auditoría de comportamiento.
3. Crear matriz de regresión por proceso.
4. Elegir una fase.
5. Crear test que falle.
6. Implementar cambio mínimo.
7. Ejecutar build/lint/tests.
8. Actualizar docs y memoria.
