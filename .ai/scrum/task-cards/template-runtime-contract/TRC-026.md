# TRC-026 — User x Document x Schema isolation scope

## Objective

Enforce durable runtime data scope keyed by runtimeSessionId + userId + documentId + schemaUid.

## Acceptance

- A/D1, A/D2, B/D1, B/D2 values remain isolated;
- changing active user or active document never contaminates another scope cell;
- scope key authority is documented and tested in runtime store.

## Evidence requirements

- integration tests for multi-user multi-document switching;
- snapshot restore test maintaining isolated value maps.

## Safety

No fallback keys based on selection order.
