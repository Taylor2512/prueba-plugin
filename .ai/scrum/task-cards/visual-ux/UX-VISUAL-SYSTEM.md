# UX-VISUAL-SYSTEM — Tokens, field chrome, i18n y lenguaje visual

## Objective
Mantener una sola autoridad visual para tokens, contraste, densidad, owner tone, field chrome,
labels técnicos y modo avanzado.

## Absorbs
VISUX-003, VISUX-028, VISUX-034, COREUX-041.

## Acceptance
- tokens sin duplicidad semántica;
- owner tone y estados visuales derivados de una sola autoridad;
- labels de producto sin IDs/modos internos innecesarios;
- contraste/a11y verificado;
- sin CSS que duplique geometría ya expresada en JSX/Tailwind.
