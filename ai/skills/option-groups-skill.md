# Option Groups Skill

## Propósito
Gestionar Radio/Checkbox/Select con IDs estables.

## Cuándo usar
Editor y runtime de opciones.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Normalizar sin perder IDs.
2. Separar label/value.
3. Preservar root.
4. Validar selección.
5. Probar UI/PDF/snapshot.
6. Probar reorder.

## Validaciones
optionId estable.

## Anti-patrones
IDs por índice o hijos como schemas.
