# Casos multi-documento/multi-página

- PDF A página 1: text, number, date, signature.
- PDF A página 2: checkboxGroup, radioGroup, dropdown.
- PDF B página 1: image, svg, barcode/QR.
- PDF B página 2: table, multiVariableText, shapes.
- Cambiar documento mantiene schemas por documentId.
- Cambiar página mantiene pageNumber.
- No-overlap se evalúa por owner/doc/page.
