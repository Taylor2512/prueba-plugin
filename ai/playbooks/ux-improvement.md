# Ux Improvement

## Objetivo

Ejecutar un procedimiento repetible dentro de una task-card.

## Precondiciones

- tarea activa;
- ownership claro;
- contexto focal;
- reglas cargadas;
- evidencia inicial.

## Procedimiento

1. Capturar flujo.
2. Clasificar problemas.
3. Definir estado objetivo.
4. Aplicar tokens/jerarquía.
5. Revisar estados.
6. Documentar.

## Salida

- causa raíz;
- cambios;
- contratos;
- evidencia;
- riesgos;
- handoff.

## Parada

No ampliar el dominio ni resolver dependencias ajenas.
