# TRC-002 — Define canonical SisadPdfmeWorkspace contract

## Objective

Define a canonical conceptual contract for portable workspace state without introducing a mega-class or runtime coupling.

## Contract target

- template: SisadPdfmeTemplate
- configuration?: SisadPdfmeConfigurationRef
- users: SisadPdfmeUser[]
- documents: SisadPdfmeDocument[]
- assignments: SisadPdfmeAssignment[]
- runtime?: SisadPdfmeRuntimeSnapshot

## Acceptance

- contract documented in .ai and represented in product types/validators;
- no React/DOM/host business semantics in contract module;
- User remains canonical identity (no new Recipient internal identity);
- clear separation between structural definition and runtime inputs.

## Required process

1. locate existing authorities for template/config/users/documents/snapshot;
2. define minimum type surface and validator boundaries;
3. wire traceability links to existing QH/PRT cards;
4. add focal tests for shape invariants and non-serializable rejection.

## Safety

Do not add a second registry, second config compiler or second snapshot format.
