# pb-git-integration

## Precondiciones
- Task activa.
- Ownership exclusivo.
- Reproducción.
- Worktree correcto.

## Procedimiento
1. Leer handoffs.
2. Comparar ramas.
3. Verificar ownership.
4. Detectar intersecciones.
5. Cherry-pick.
6. Gate.
7. Publicar.

## Salida
Diff mínimo, pruebas focales, commit y handoff.

## Parada
No ampliar scope ni corregir dependencias ajenas.
