# TRC-047 — Structured workspace change events

## Objective

Define stable event taxonomy and payload for workspace-level mutations.

## Event set

template.changed, schema.created/updated/deleted, users.changed, assignments.changed, document.changed, config.changed, snapshot.restored.

## Payload minimum

eventId, transactionId, entity IDs, origin, revision, reason.

## Acceptance

- events emitted consistently on successful mutations;
- payload excludes unnecessary sensitive values;
- event-contract tests validate schema and sequencing basics.

## Safety

No event emission from speculative/aborted mutations.
