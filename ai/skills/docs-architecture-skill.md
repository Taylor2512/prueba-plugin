# Docs Architecture Skill

## Propósito
Refactorizar docs sin perder historia.

## Cuándo usar
Duplicidad y obsolescencia.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Clasificar temporalidad.
2. Una responsabilidad.
3. Compactar memoria.
4. Archivar historia.
5. Actualizar índices.
6. Validar links.

## Validaciones
Estado actual consistente.

## Anti-patrones
Borrar sin redirección.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
