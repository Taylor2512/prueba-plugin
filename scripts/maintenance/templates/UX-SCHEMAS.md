# UX-SCHEMAS — Inspector y experiencia visual por capability

## Objective
Consolidar perfiles de inspector y UI por schema family/capability.

## Absorbs
VISUX-029..033, VISUX-036 y COREUX-029,035,036,038,041,045.

## Acceptance
- inspector derivado de registry/manifest/capabilities;
- choice fields usan una sola option authority;
- signing distingue identidad, adoption style y execution method;
- action/media/barcode/table/shapes sin ramas visuales ad-hoc;
- read -> write -> persist -> Form -> Viewer -> PDF -> Snapshot parity.
