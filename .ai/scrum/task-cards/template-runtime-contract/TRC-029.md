# TRC-029 — External plugin configuration in portable JSON

## Objective

Persist required schema/plugin type declarations without serializing executable plugin implementations.

## Acceptance

- portable JSON carries requiredSchemaTypes (or equivalent declarative contract);
- import preflight resolves required types against live registry;
- missing types fail closed with MISSING_SCHEMA_PLUGIN issue.

## Safety

Do not serialize render/propPanel/provider functions.
