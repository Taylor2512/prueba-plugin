# sisad-task-orchestration

## Procedimiento

1. Validar Ready y presupuesto.
2. Asignar un writer.
3. Permitir hasta dos lectores.
4. Cerrar con evidence y memory delta.

## Evidencia mínima

- rutas y símbolos;
- test o reproducción;
- decisión;
- riesgos;
- condición de parada.

No cargar esta skill fuera de su dominio.
