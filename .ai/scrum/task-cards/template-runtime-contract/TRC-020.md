# TRC-020 — Formal separation: Template vs Snapshot vs Runtime

## Objective

Document and enforce boundaries between reusable template definition, restorable snapshot state and live runtime memory.

## Acceptance

- explicit type boundaries and mapping functions;
- snapshot includes restorable execution state but excludes non-portable runtime internals;
- template remains reusable and session-agnostic;
- runtime memory remains process/session scoped.

## Evidence requirements

- boundary tests proving fields are accepted/rejected at each layer;
- docs updated with examples for each layer.

## Safety

No layer should absorb responsibilities of another.
