# Troubleshooting de integración externa

## Alias no resuelto

Revise Vite y TypeScript.

## Tailwind no genera clases

Incluya la carpeta copiada en `content`.

## Worker PDF.js

Use `configurePdfjsWorker`.

## Pantalla vacía

Revise altura, template y consola.

## Dos React

```bash
npm ls react react-dom
```

## Documento sin schemas

Preserve `document.template`.

## Estado vuelve atrás

El campo es controlado y el host no devolvió el nuevo valor.

## Bundle inválido

Retire funciones, File, DOM, React, adapters y recursos vivos.
