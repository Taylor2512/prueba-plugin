# Reglas — UX inspirada en DocuSign/Wix sin copiar marca

- No copiar colores, CSS, textos propietarios ni nombres internos.
- Usar patrones generales: campo pequeño, grupo punteado, botón `+`, inspector derecho compacto.
- El PDF siempre es protagonista; los schemas son overlays ligeros.
- Idle: fondo ownerColor 6–10%, borde 1px.
- Selected: borde claro máximo 1.5px, handles pequeños.
- Grupos: borde punteado suave, options alineadas, botón `+` integrado.
- No mostrar `checkboxGroup`, `radioGroup`, `groupId`, `optionId` como contenido principal.
- Metadata técnica solo en sección Avanzado colapsada.
