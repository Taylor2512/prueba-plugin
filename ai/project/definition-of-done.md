# Definition of Done

Una task está completa cuando:

- [ ] causa raíz documentada;
- [ ] ownership respetado;
- [ ] diff mínimo;
- [ ] sin duplicidad;
- [ ] sin CSS prohibido;
- [ ] sin expected falsos;
- [ ] ESLint focal;
- [ ] Vitest focal;
- [ ] Playwright focal cuando aplica;
- [ ] diff check;
- [ ] commit atómico;
- [ ] handoff;
- [ ] lock liberado.

Una wave está completa cuando el gate global pasa y `main` avanza por fast-forward.
