# Canvas Multipage Skill

## Propósito
Modificar Canvas preservando identidad.

## Cuándo usar
Papers, páginas y overlays.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Mapear IDs.
2. Reproducir página 2+.
3. Separar coordenadas.
4. Cambiar scroll owner.
5. Validar drop/selection.
6. Ejecutar specs.

## Validaciones
No mezclar stage/PDF.

## Anti-patrones
Asumir una página.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
