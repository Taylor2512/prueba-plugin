# Git Integration Skill

## Propósito
Integrar commits con trazabilidad.

## Cuándo usar
Cierre de wave.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Comparar ramas.
2. Verificar ownership.
3. Detectar dependencias.
4. Cherry-pick.
5. Resolver o devolver conflictos.
6. Gate.
7. Registrar.
8. Publicar.

## Validaciones
Gate completo y main limpio.

## Anti-patrones
Merge de ramas completas o force.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
