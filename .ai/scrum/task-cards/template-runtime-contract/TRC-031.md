# TRC-031 — Portable comments registry

## Objective

Stabilize portable comment identity and anchors across documents/pages/schemas.

## Required fields

commentId, schemaUid, documentId?, pageIndex?, authorUserId, createdAt, resolved, replies, anchor.

## Acceptance

- comments survive snapshot round-trip with identity preserved;
- author identity references user registry (not name-only);
- anchor validation rejects invalid schema/page references.

## Safety

No comment identity from display-only authorName.
