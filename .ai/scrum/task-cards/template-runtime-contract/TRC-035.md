# TRC-035 — Full lock accessibility matrix

## Objective

Harden accessibility for readOnly, positionLocked and collaboration lock controls.

## Required coverage

aria-label, aria-pressed, tooltip, keyboard path, focus return, disabled reason, screen-reader text, high contrast, touch target.

## Acceptance

- accessibility specs implemented and tested;
- keyboard-only flow can toggle/read state where policy allows;
- screen readers can disambiguate lock types.

## Safety

No icon-only semantics.
