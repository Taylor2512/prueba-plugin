# Visual UX execution policy

- Task dependencies live in VISUX task cards.
- WIP default: maximum 3 concurrent tasks.
- Maximum one `very-high` risk task in active implementation.
- One writer per overlapping file.
- A VISUX and related COREUX task must not edit the same files concurrently.
- If COREUX fully absorbs a VISUX requirement, evidence the absorption instead of creating a
  second implementation authority.
- Same repo/same branch policy applies; no worktree requirement.
