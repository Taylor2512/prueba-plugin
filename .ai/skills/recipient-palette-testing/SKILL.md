# Skill — Recipient palette testing

## Objetivo

Evitar que dos destinatarios compartan color en pruebas.

## Tests esperados

- `resolveRecipientColor` devuelve color explícito.
- Fallback estable por id.
- Paleta sin repetidos cuando hay suficientes colores.
- Chips de destinatarios tienen colores distintos.
- Cambiar usuario cambia color del catálogo.
