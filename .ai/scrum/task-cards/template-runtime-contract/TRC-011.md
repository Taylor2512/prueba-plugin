# TRC-011 — Explicit collaboration lock runtime model

## Objective

Define collaboration lock as runtime/session state with explicit lease semantics and clear separation from durable schema config.

## Target model

- schemaUid
- userId
- leaseId
- acquiredAt
- expiresAt?

## Acceptance

- readOnly, positionLocked, collaborationLock remain separate authorities;
- lease lifecycle covers acquire/release/expiry/stale/reconnect;
- lock ownership states none/mine/other/unknown are policy-observable;
- local undo/redo excludes remote lease history unless explicitly contracted.

## Evidence requirements

- integration tests for A vs B contention and stale lease handling;
- reconnect/disconnect resilience checks;
- policy tests for lock reason exposure and disabled actions.

## Safety

Do not persist ephemeral lease as durable template definition.
