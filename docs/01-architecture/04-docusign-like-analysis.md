# Análisis DocuSign-like

## Referencia funcional

DocuSign trabaja con documentos, recipients y tabs/campos.

## Procesos aplicables

- ubicación fija;
- anchor/AutoPlace;
- required/locked;
- dataLabel;
- tooltip;
- validation;
- checkbox groups;
- radio groups;
- prefill;
- inspector;
- audit.

## Regla

No copiar marca ni UI propietaria.
