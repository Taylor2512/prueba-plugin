# TRC-008 — Canonical Assignment registry contract

## Objective

Define canonical assignment contract and separate durable assignment from readOnly/positionLocked/collaboration lock semantics.

## Target shape

- id
- schemaUid
- userIds[]
- mode: single | shared
- valueScope: shared | per-user

## Acceptance

- assignment references are validated against existing schemas/users;
- contradictory duplicates are rejected;
- no conflation with runtime collaboration locks;
- import/export/snapshot preserve assignment semantics.

## Required process

1. characterize current assignment authority;
2. codify validator and normalization rules;
3. add contract tests for orphan/duplicate/conflict cases;
4. link with runtime scope card TRC-026.

## Safety

No business routing semantics in assignment mode/valueScope.

## Evidence executed — 2026-08-18 (PARTIAL)

- Canonical `SisadPdfmeAssignment` contract added and exported from contract barrels.
- Workspace validator keeps assignment checks for required `schemaUid` + `userIds` and unknown-user references fail closed.
- Unit tests confirm orphan user reference detection (`WORKSPACE_INVALID_REFERENCE`).
- Workspace validator now resolves `schemaUid` against the template schema registry and rejects duplicate assignment rows.
- Workspace validator fails closed when assignments exist without any schema registry and enforces canonical `mode`/`valueScope` shape.
- Unit tests now cover missing schema references, duplicate assignment rows, and the no-registry fail-closed path in the canonical workspace contract.

### Why PARTIAL

- Import/export/snapshot parity and the runtime-scope handoff to TRC-026 remain for later slices (TRC-004/TRC-005/TRC-017/TRC-026).
