# Política documental

Cada documento temporal debe clasificarse:

```txt
current
historical
superseded
external
```

## Current

Describe el estado vigente.

## Historical

Conserva hechos anteriores.

## Superseded

Fue reemplazado y debe indicar el sustituto.

## External

Pertenece a otro sistema o repositorio.

## Reglas

- Una responsabilidad por archivo.
- No copiar conversaciones.
- No pegar logs extensos en memoria.
- Métricas con fecha o identificador de versión.
- No borrar planes sin redirección.
