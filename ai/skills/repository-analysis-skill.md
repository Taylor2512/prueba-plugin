# Repository Analysis Skill

## Propósito
Analizar un repositorio grande sin auditoría ilimitada.

## Cuándo usar
Arquitectura, duplicidad o planificación.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Definir preguntas.
2. Mapear fronteras.
3. Muestrear símbolos.
4. Clasificar hallazgos.
5. Separar evidencia e inferencia.
6. Proponer slices.

## Validaciones
Citar rutas y no inventar.

## Anti-patrones
Leer todo y generar listas sin prioridad.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
