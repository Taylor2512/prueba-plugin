# TRC-025 — Schema codec registry semantic contract

## Objective

Define codec semantics per schema type for undefined/null/empty/falsey values without Boolean(value) shortcuts.

## Required codec operations

decode, encode, isEmpty, equals, normalize

## Acceptance

- per-type codec behavior is explicit and tested;
- falsey values (0,false,"") preserve intended semantics;
- Form/Viewer/Snapshot parity uses shared codec outcomes.

## Evidence requirements

- table-driven codec tests for common and edge values;
- cross-surface integration checks for selected schema families.

## Safety

No ad-hoc coercion outside codec authority.
