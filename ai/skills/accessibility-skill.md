# Accessibility Skill

## Propósito
Validar teclado y semántica.

## Cuándo usar
Controles y dialogs.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Nombre accesible.
2. Roles nativos.
3. Tab/Escape/Enter.
4. Restaurar foco.
5. Disabled reason.
6. Motion/contraste.

## Validaciones
Sin teclado atrapado.

## Anti-patrones
ARIA genérica o tabindex positivo.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
