# QH-014 — Flujo E2E de candado hasta Preview/Viewer/Form

## Objetivo

Demostrar que el toggle del Designer no es sólo estado local: el snapshot actualizado debe producir el mismo comportamiento en Preview, Viewer y Form.

## Casos mínimos

1. Campo editable → activar solo lectura → editar propiedades, texto y valor: todo se rechaza con razón `readonly`; seleccionar/inspeccionar/exportar continúa.
2. Solo lectura → desactivar → edición vuelve a estar disponible y se registra una nueva entrada de historial.
3. Posición bloqueada → move/resize/delete rechazados; contenido conserva la policy establecida.
4. Lock colaborativo ajeno → todas las acciones mutantes deshabilitadas con owner; liberar edición no aparece o queda rechazado.
5. Selección mixta → indicador `mixed`; aplicar toggle pide una decisión determinista y no deja schemas divergentes sin evento.
6. Recarga, cambio de página, exportación y apertura del runtime conservan el estado.

## Archivos/artefactos

Cubrir `Designer`, `Preview`, `Viewer`, `SisadPdfmePreviewRuntime`, `schemaRuntimeAccess`, command bus, collaboration adapter y snapshots de template. Adjuntar trace sólo para fallos y screenshot de cada estado visual.
