# Inspector Skill

## Propósito
Mantener inspector persistente y compacto.

## Cuándo usar
DetailView/ListView.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Identificar perfil.
2. Verificar read/write.
3. Derivar visible/disabled.
4. Mantener scroll owner.
5. Agrupar secciones.
6. Validar matrix.

## Validaciones
No control sin write real.

## Anti-patrones
Labels paralelos o inputs cortados.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
