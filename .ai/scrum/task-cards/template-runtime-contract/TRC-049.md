# TRC-049 — Semantic template diff projection

## Objective

Provide canonicalizeTemplateForDiff projection to decide if a real persistible change exists.

## Acceptance

- projection ignores non-durable/transient fields;
- meaningful structural/config changes are detected deterministically;
- host versioning decisions can rely on diff output.

## Evidence requirements

- fixtures for no-op vs real-change scenarios;
- explicit diff examples in docs/evidence.

## Safety

No raw deep-diff of full runtime object graphs.
