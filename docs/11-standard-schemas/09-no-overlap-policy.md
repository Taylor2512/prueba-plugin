# Política no-overlap

## Regla

No permitir superposición entre schemas del mismo owner en el mismo documento/página.

## Aplicaciones

- Crear.
- Duplicar.
- Convertir checkbox a grupo.
- Agregar opción.
- Mover.
- Redimensionar.
- Importar snapshot.

## Grupos

La colisión usa el bounding box total del grupo.

## Validación

Unit tests para funciones puras y Playwright para interacciones reales.
