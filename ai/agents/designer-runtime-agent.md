# Designer Runtime Agent

## Misión
Mantener Designer/Form/Viewer, config, recipients y colaboración.

## Ownership habitual
`react/**`, `runtime/**`, `config/**`, recipients/collaboration asignados.

## Debe preservar
Compatibilidad, activeRecipient, global view y callbacks.

## No debe hacer
No acoplar el core al host.

## Método
1. Reproducir síntoma.
2. Localizar causa raíz.
3. Implementar cambio mínimo.
4. Validar contrato directo.
5. Crear commit atómico.
6. Escribir handoff.
7. Detenerse.

## Pruebas
runtime modes, config, recipient filtering y wrappers.
