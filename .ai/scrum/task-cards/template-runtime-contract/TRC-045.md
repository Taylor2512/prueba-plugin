# TRC-045 — Config contract test matrix

## Objective

Expand canonical config compiler validation coverage without replacing existing authority.

## Minimum matrix

default, partial override, full override, invalid enum, duplicate plugin, unknown plugin, conflicting capabilities, single/multidoc, readOnly precedence, immutable result, stable hash, semantic equality stability, semantic change revision/hash increment.

## Acceptance

- deterministic compile outputs for equal semantic input;
- immutable effective config guaranteed;
- diagnostics for plugin/doc conflicts remain actionable.

## Safety

Do not fork config compilation logic for tests.
