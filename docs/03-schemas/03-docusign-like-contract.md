# DocuSign-like Contract

Referencia funcional, no copia visual. Propiedades comunes: destinatario, required, readOnly, tooltip, dataLabel, ubicación, autoPlace, permisos, validación, condicionales y colaboración. Mapeo: SignHere->signature, InitialHere->initials, Text->text, Number->number, Checkbox->checkbox, RadioGroup->radioGroup, List->select/dropdown, DateSigned->dateSigned, Attachment->attachment.
