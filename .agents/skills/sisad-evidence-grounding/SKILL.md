# sisad-evidence-grounding

## Procedimiento

1. Crear claim ledger.
2. Buscar ruta/test/fuente.
3. Etiquetar inferencias.
4. Retractar claims falsos.

## Evidencia mínima

- rutas y símbolos;
- test o reproducción;
- decisión;
- riesgos;
- condición de parada.

No cargar esta skill fuera de su dominio.
