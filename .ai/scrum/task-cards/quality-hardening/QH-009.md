# QH-009 — Auditoría Tailwind y CSS técnico

La hoja `ui/styles/sisad-pdfme.css` se mantiene como frontera técnica: tokens runtime, pseudo-elemento de grid, Moveable/Scena, datasets, backgrounds multicapa y reduced-motion de Ant Design. Layout, spacing, sizing, typography, responsive y chrome propio permanecen en JSX/Tailwind.

No migrar CSS técnico sólo para reducir líneas ni introducir `@apply` o una segunda autoridad visual.
