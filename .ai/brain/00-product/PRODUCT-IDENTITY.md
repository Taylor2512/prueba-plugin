# Product Identity — SISAD-PDFME

## Canon

- Nombre actual: **SISAD-PDFME**.
- Identidad: plataforma reusable propia para diseñar, llenar, visualizar, generar y
  transportar documentos PDF con schemas, colaboración y configuración declarativa.
- Antecedente: inspirada históricamente en pdfme.
- Prohibido describir el producto actual como “pdfme con modificaciones”.

## Nomenclatura

Todo código nuevo usa `SisadPdfme*` / `SISAD-PDFME`. Los nombres históricos `Pdfme*` se
mantienen temporalmente solo donde un cambio rompería compatibilidad o generaría un diff de
nomenclatura demasiado grande para una task funcional. `RTP-330` sanea esto al final.
