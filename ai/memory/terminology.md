# Terminología

| Término | Definición |
|---|---|
| Schema | Elemento posicionado en una página |
| Recipient | Actor o destinatario |
| Owner | Propietario persistido del schema |
| Assignment | Relación schema-recipient |
| Paper | Superficie de página |
| Stage | Contenedor visual |
| Snapshot | Estado serializable |
| Handoff | Transferencia entre agentes |
| Task-card | Unidad concreta de trabajo |
