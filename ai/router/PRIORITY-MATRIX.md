# Matriz de prioridad

## P0 — Bloqueante

- pérdida de datos;
- aplicación bloqueada;
- persistencia incorrecta;
- selección imposible;
- flujo principal inutilizable;
- vulnerabilidad crítica.

## P1 — Alta

- navegación rota;
- scroll roto;
- permisos incorrectos;
- modal que bloquea;
- acción principal inaccesible;
- regresión funcional importante.

## P2 — Media

- densidad;
- inconsistencia visual;
- feedback deficiente;
- accesibilidad parcial;
- rendimiento localizado.

## P3 — Baja

- polish;
- limpieza;
- documentación;
- optimización no crítica.
