# TRC-009 — Propagate readOnly to Form/Viewer/Snapshot

## Objective

Close end-to-end propagation gap for durable readOnly semantics from Designer command to runtime surfaces.

## Contract matrix

- Designer unlocked -> schema.readOnly=false -> snapshot false -> Form editable -> Viewer readonly by surface policy.
- Designer readOnly -> schema.readOnly=true -> snapshot true -> Form readonly -> Viewer readonly.
- positionLocked=true does not force Form readonly.
- collaborationLock is runtime-temporal and must not overwrite durable readOnly.

## Acceptance

- command -> policy -> mutation -> snapshot -> restore -> Form/Viewer parity demonstrated;
- undo/redo preserves readOnly semantics;
- reload/import preserves readOnly semantics;
- QH-013/QH-014 overlap documented with residuals.

## Evidence requirements

- E2E for lock/save/export/reload/import/form/viewer/unlock/undo/redo;
- unit for policy precedence readOnly vs positionLocked vs collaboration lock;
- snapshot fixture assertions for durable flag persistence.

## Safety

No UI-only closure without runtime and snapshot evidence.
