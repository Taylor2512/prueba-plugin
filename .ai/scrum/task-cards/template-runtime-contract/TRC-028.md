# TRC-028 — Portable package layout

## Objective

Define portable package envelope once template and snapshot contracts are stable.

## Target layout

manifest.json, template.json, snapshot.json, assets/

## Acceptance

- package manifest references versions/checksums/compatibility markers;
- assets are referenced portably without embedding runtime-only handles;
- import preflight validates package completeness before hydrate.

## Safety

No plugin/callback implementations inside portable package.
