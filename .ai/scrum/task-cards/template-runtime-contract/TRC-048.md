# TRC-048 — Durable template dirty semantics

## Objective

Track dirty state only for persistible template changes.

## Must not mark dirty

selection, hover, zoom, scroll, panel/search state, shortcut overlay UI.

## Must mark dirty

schema create/delete/update, readOnly, positionLocked, assignment changes, user resource changes, document structural changes, portable config changes.

## Acceptance

- dirty reducer/state machine documented and tested;
- semantic no-op updates do not mark dirty.

## Safety

No UI transient state in persistibility signal.
