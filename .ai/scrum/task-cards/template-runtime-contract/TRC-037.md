# TRC-037 — Semantic undo/redo boundaries for lock commands

## Objective

Guarantee undo/redo boundaries reflect durable command semantics for readOnly and positionLocked.

## Acceptance

- readOnly on/off undo/redo deterministic;
- positionLocked on/off undo/redo deterministic;
- combined operations preserve command boundaries;
- collaboration lease events excluded from local history unless explicit contract.

## Safety

No history conflation between durable and ephemeral lock channels.
