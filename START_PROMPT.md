# Prompt de arranque compacto

Actúa como arquitecto frontend senior para `sisad-pdfme`. Antes de modificar código, lee `AGENTS.md`, `.ai/INDEX.md`, `.ai/context-map.md` y `.ai/memory/project-memory.md`. Selecciona solo 1 contexto principal, máximo 2 reglas y 1 prompt. Para esta tarea prioriza `standard-fields-groups-context.md`, `standard-fields-group-contract-rules.md` y `harden-standard-fields-groups.prompt.md`. Usa `rg` para localizar implementación real. No reescribas coordenadas, collision, Moveable, Selecto, snapshot ni renderers si no existe prueba de bug. Cierra primero contrato, identidad, no-overlap, DetailView, snapshot, Form/Viewer/Generator y tests. Ejecuta `npm run build -- --mode development`, `npm run lint` y tests focalizados o documenta el bloqueo real.
