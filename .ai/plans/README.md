# Plans

This directory is intentionally empty of active architecture plans.

Authority is stored in:

- current contracts and ADRs under `.ai/brain/`;
- current procedural guides and skills;
- task-cards under `.ai/scrum/task-cards/`;
- executed evidence under `reports/`.

Historical plans were removed during pre-production canonization. Git retains
their history; they are not runtime or architecture authorities.
