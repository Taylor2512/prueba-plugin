# Snapshot Engine

## Propósito

Representar el estado completo y portable de `sisad-pdfme`.

## Debe incluir

- Versión.
- Documentos.
- Páginas.
- Schemas.
- Coordenadas.
- Propiedades.
- Permisos.
- Assignments si están activos.
- Comentarios si están activos.
- Configuración visual.

## No debe incluir

- Tokens.
- Credenciales.
- DOM.
- Funciones.
- Estados temporales innecesarios.
