# TRC-019 — Deterministic Template JSON export

## Objective

Guarantee stable canonical export for semantically equivalent states.

## Canonicalization scope

user ordering, document ordering, schema ordering, assignment ordering, metadata filtering, key ordering policy (if used).

## Rejected export noise

timestamps, runtime random IDs, hover/selection/search/panel state, drag transient, object URLs.

## Acceptance

- two semantically equal states produce equal canonical export;
- deterministic serializer tests cover ordering and filtering;
- diff noise from non-durable state is removed.

## Safety

Do not remove durable fields during normalization.
