# Color State Separation

## Propósito

Separar owner color, selected, favorite, hover y focus.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Inventariar estados.
2. Definir tokens.
3. Eliminar ambigüedad.
4. Aplicar jerarquía.
5. Revisar disabled/locked.
6. Documentar.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No usar un color para varios significados.
