# Ux Audit

## Propósito

Clasificar problemas UX.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Capturar flujo.
2. Separar funcional/layout/visual/a11y.
3. Priorizar.
4. Definir estado objetivo.
5. Mapear componentes.
6. Crear tareas.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No confundir estética con contrato.

## Salida

```md
## Alcance
## Evidencia
## Procedimiento aplicado
## Resultado
## Riesgos
## Dependencias
```
