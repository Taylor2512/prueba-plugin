# Casos de uso — Auditoría visual de schemas

## Objetivo

Validar que todos los schemas son ligeros, legibles, no invasivos y no se solapan.

## Schemas

Text, Number, Checkbox, CheckboxGroup, RadioGroup, Select/Dropdown, Signature, Date, DateTime, Time, Image, SVG, Barcode/QR, Table, MultiVariableText, Line, Rect, Ellipse.

## Casos

- Insertar todos los schemas.
- Distribuir entre páginas/PDFs.
- Medir overlap por owner.
- Verificar que no salgan del paper.
- Verificar PDF legible.
- Verificar toolbar no tapa completamente.
