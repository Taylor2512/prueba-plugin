# Test Stabilization

## Objetivo

Ejecutar un procedimiento repetible dentro de una task-card.

## Precondiciones

- tarea activa;
- ownership claro;
- contexto focal;
- reglas cargadas;
- evidencia inicial.

## Procedimiento

1. Capturar fallos.
2. Agrupar causas.
3. Clasificar.
4. Asignar owners.
5. Resolver focal.
6. Actualizar reporte.

## Salida

- causa raíz;
- cambios;
- contratos;
- evidencia;
- riesgos;
- handoff.

## Parada

No ampliar el dominio ni resolver dependencias ajenas.
