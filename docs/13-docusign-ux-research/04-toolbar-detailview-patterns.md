# Toolbar contextual y DetailView

## Toolbar

Debe mostrar pocas acciones:

- Single schema: Editar, Duplicar, Más.
- Group: Agregar opción/casilla, Duplicar, Más.
- Multi-selection: Duplicar, Eliminar, Alinear, Distribuir, Más.

No debe tapar completamente el documento.

## DetailView

- Identidad y Caja visibles.
- Opciones y Validación para grupos.
- Colaboración/Datos conectados compactos.
- Avanzado colapsado para IDs técnicos.
