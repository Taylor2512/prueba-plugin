# TRC-050 — Integral portable contract closeout

## Objective

Close the full portable runtime contract only after all mandatory gates are evidence-pass.

## Mandatory checklist

template JSON roundtrip, config roundtrip, users registry, schema registry, assignment integrity, multidoc, multiuser, readOnly, positionLocked, collaboration lock (or explicit runtime-only policy), group identity, snapshot, Form, Viewer, PDF, shortcut registry, accessibility, visual regression.

## Required gates

npm test; npm run typecheck; npx eslint . --max-warnings=0; npm run build; npm run test:e2e; quality gates (architecture/dead-code/cycles/duplicates); docs and architecture audit/verify; serena index/health-check; git diff --check.

## Acceptance

- every checklist item mapped to executed evidence;
- residual risks explicitly documented;
- no PASS inferred from partial proxies.

## Safety

Do not close campaign with unexecuted mandatory gates.
