# Memory Maintenance

## Propósito

Actualizar memoria compacta.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Leer handoff.
2. Actualizar estado.
3. Decisiones.
4. Riesgos.
5. Pendientes/completados.
6. Changelog.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No logs.

## Salida

```md
## Alcance
## Evidencia
## Procedimiento aplicado
## Resultado
## Riesgos
## Dependencias
```
