# TRC-036 — Mixed-selection lock semantics

## Objective

Represent all unlocked/all locked/mixed states deterministically for multi-selection.

## Acceptance

- mixed state is explicitly rendered;
- lock/unlock/readOnly/editable all execute as single transaction boundary;
- no partial silent mutation on heterogeneous selection.

## Evidence requirements

- unit for mixed reducer/aggregator;
- E2E for multi-select action and undo boundary.

## Safety

Do not collapse mixed into false.
