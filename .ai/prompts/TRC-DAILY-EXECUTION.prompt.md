# TRC-DAILY-EXECUTION.prompt.md

Execute one day from the TRC day-by-day plan with strict evidence handling.

## Inputs

- selected day from .ai/scrum/views/TRC-DAY-BY-DAY-2W.md
- linked card(s)
- current evidence and dependencies

## Required flow

1. verify dependencies and overlap with QH/PRT/RTP
2. characterize current behavior
3. implement minimum safe slice
4. run focal gates
5. update evidence and status from facts only
6. prepare handoff to next day

## Required output

- objective achieved/partial/blocked
- files changed
- commands executed and results
- non-executed gates and reason
- blockers and risk notes
- next-day recommendation
