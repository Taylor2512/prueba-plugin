# Runtime Integration Skill

## Propósito
Conectar host con wrappers públicos.

## Cuándo usar
Designer/Form/Viewer.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Usar fachada.
2. Normalizar una vez.
3. Modo explícito.
4. Propagar recipient/view.
5. Conectar inputs.
6. Probar runtimes.

## Validaciones
Host no importa internals.

## Anti-patrones
commonOptions dispersos.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
