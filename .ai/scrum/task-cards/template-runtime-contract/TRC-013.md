# TRC-013 — Portable schema flattening authority (not renderer authority)

## Objective

Move durable portable schema authority from Schema[][] to canonical flat collection keyed by schemaUid/documentId/pageIndex.

## Acceptance

- portable JSON authority uses flat schemas array;
- renderer projection keeps groupBy(document/page) compatibility;
- migration strategy from legacy nested shape is explicit and tested;
- no behavior regression in Designer/Form/Viewer generation path.

## Evidence requirements

- migration tests nested -> flat -> renderer projection;
- deterministic ordering contract for flat output.

## Safety

Do not force internal renderer structure into durable JSON.
