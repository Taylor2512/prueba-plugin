# Visual Regression Skill

## Propósito
Detectar regresiones con evidencia.

## Cuándo usar
UI y responsive.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Fijar viewport/datos.
2. Capturar before/after.
3. Comparar regiones.
4. Validar interacción.
5. Registrar métricas.
6. Crear test estable.

## Validaciones
Ruta, commit y viewport.

## Anti-patrones
Aprobar por memoria.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
