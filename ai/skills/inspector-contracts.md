# Inspector Contracts

## Propósito

Garantizar persistencia real de controles.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Identificar perfil.
2. Verificar read.
3. Verificar write.
4. Verificar validation.
5. Verificar disabled reason.
6. Documentar.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No controles decorativos.

## Salida

```md
## Alcance
## Evidencia
## Procedimiento aplicado
## Resultado
## Riesgos
## Dependencias
```
