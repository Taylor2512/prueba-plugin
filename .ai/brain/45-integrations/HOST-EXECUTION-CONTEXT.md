# Host execution -> SISAD-PDFME Form

The host authenticates/authorizes its participant and resolves:

- active User;
- active Document;
- serializable inputs;
- access projection;
- signature context;
- resources;
- opaque runtime session scope.

SISAD-PDFME executes Form and returns generic values/events/artifacts.

SISAD-PDFME does not choose the next participant, compute host workflow completion or fan
out host requests.
