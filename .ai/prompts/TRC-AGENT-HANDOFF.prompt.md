# TRC-AGENT-HANDOFF.prompt.md

Prepare a clean handoff between agents for a TRC slice.

## Handoff package

- card ID and status
- changed files list
- executed gates with command and result
- non-executed gates with reason
- evidence links and residual acceptance gaps
- explicit next-step card and preconditions

## Quality rules

- no narrative-only handoff
- no hidden assumptions about gate results
- no status promotion without evidence mapping
