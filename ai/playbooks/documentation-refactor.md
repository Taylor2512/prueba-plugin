# Documentation Refactor

## Objetivo

Ejecutar un procedimiento repetible dentro de una task-card.

## Precondiciones

- tarea activa;
- ownership claro;
- contexto focal;
- reglas cargadas;
- evidencia inicial.

## Procedimiento

1. Inventario.
2. Clasificación.
3. Fuente única.
4. Migración.
5. Índice.
6. Validación.

## Salida

- causa raíz;
- cambios;
- contratos;
- evidencia;
- riesgos;
- handoff.

## Parada

No ampliar el dominio ni resolver dependencias ajenas.
