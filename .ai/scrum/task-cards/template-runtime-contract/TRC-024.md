# TRC-024 — Registry-driven schema defaults only

## Objective

Eliminate parallel default schema sources and centralize defaults in registry/plugin factories.

## Required pipeline

registry.resolve(type) -> factory/defaultSchema() -> normalize -> assign identity -> insert

## Acceptance

- no duplicate defaults in LeftSidebar, Designer insertion, fixtures, Form or importer;
- undefined defaults cannot erase generated IDs;
- contract tests assert default parity across insertion paths.

## Safety

Do not bypass registry for schema creation.
