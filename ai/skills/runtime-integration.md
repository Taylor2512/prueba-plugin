# Runtime Integration

## Propósito

Conectar config, recipients y callbacks.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Usar API pública.
2. Normalizar.
3. Resolver modo.
4. Propagar actor.
5. Conectar callbacks.
6. Documentar.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No internals.
