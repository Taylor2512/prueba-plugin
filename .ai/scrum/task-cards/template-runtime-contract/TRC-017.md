# TRC-017 — Aggregate Template JSON preflight validator

## Objective

Provide validateSisadPdfmeTemplate with structured issues for parse/version/entity/reference/portability failures.

## Issue shape

- code
- severity
- path
- entityId
- message
- hint?

## Minimum validations

JSON parse, schemaVersion, template identity, users, documents, schemas, assignments, registry type, aliases, duplicate IDs, orphan references, invalid pages/coordinates/options/signature/artifacts, unsupported config, non-serializable metadata.

## Acceptance

- validator returns deterministic structured issues;
- import pipeline consumes issues fail-closed;
- error codes documented and covered by contract tests.

## Safety

No silent repairs in validator path.
