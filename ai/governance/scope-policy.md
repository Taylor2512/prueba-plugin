# Política de alcance

## Límites recomendados

```txt
1 tarea
1 dominio principal
máximo 5 archivos productivos
máximo 2 búsquedas globales
máximo 8 archivos fuente abiertos
1 entrega coherente
```

## Excepciones

Solo para:

- migraciones versionadas;
- refactors aprobados;
- cambios de API pública;
- incidentes;
- planes de estabilización.

## Anti-patrones

- “Ya que estoy aquí…”
- corregir warnings ajenos;
- renombrar carpetas durante un bugfix;
- mezclar UX con persistencia;
- crear otra abstracción sin contrato.
