# Tailwind Migration

## Propósito

Migrar skin seguro a Tailwind.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Clasificar propiedad.
2. Mover estático.
3. Conservar dinámico.
4. Preservar técnico.
5. Eliminar dead.
6. Documentar.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

Sin @apply, global CSS o doble fuente.
