# Inspector Regression

## Objetivo

Ejecutar un procedimiento repetible dentro de una task-card.

## Precondiciones

- tarea activa;
- ownership claro;
- contexto focal;
- reglas cargadas;
- evidencia inicial.

## Procedimiento

1. Identificar familia.
2. Verificar profile/map.
3. Reproducir persistencia.
4. Corregir widget/resolver.
5. Revisar scroll.
6. Documentar.

## Salida

- causa raíz;
- cambios;
- contratos;
- evidencia;
- riesgos;
- handoff.

## Parada

No ampliar el dominio ni resolver dependencias ajenas.
