# Visual Regression

## Propósito

Comparar visual con evidencia.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Fijar viewport.
2. Fijar datos.
3. Capturar before.
4. Capturar after.
5. Comparar regiones.
6. Registrar.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No aprobar por memoria.
