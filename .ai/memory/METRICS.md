# METRICS

## Por sprint

- task-cards terminadas;
- lead time;
- rework;
- rollbacks;
- claims retractados;
- loops detenidos;
- contexto máximo;
- archivos abiertos/modificados;
- consumo relativo por clase de modelo;
- tests agregados;
- duplicidad owned;
- regresiones visuales;
- decisiones reabiertas.

Guardar tendencias, no dumps.
