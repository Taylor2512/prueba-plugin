# Distribución de campos como editor profesional

No se debe concentrar todo en una misma zona.

## Reglas

- Usar todas las páginas disponibles.
- Usar más de un PDF en demos.
- No overlap por owner/doc/page.
- Si un schema grande no cabe, buscar otra zona/página.
- Grupos crecen dentro de page bounds.
- Si no hay espacio, feedback claro.
