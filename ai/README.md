# Arquitectura IA

## Objetivo

Organizar el trabajo de agentes de IA especializados sin duplicidad, pérdida de contexto o ampliaciones de alcance.

## Lectura mínima

```txt
START.md
governance/operating-principles.md
router/ROUTER.md
memory/current-state.md
tasks/active/<TASK>.md
```
