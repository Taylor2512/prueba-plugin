# Schema Extension

## Objetivo

Ejecutar un procedimiento repetible dentro de una task-card.

## Precondiciones

- tarea activa;
- ownership claro;
- contexto focal;
- reglas cargadas;
- evidencia inicial.

## Procedimiento

1. Contrato.
2. Factory.
3. Metadata.
4. UI/PDF.
5. Values/validation.
6. Runtime/snapshot.

## Salida

- causa raíz;
- cambios;
- contratos;
- evidencia;
- riesgos;
- handoff.

## Parada

No ampliar el dominio ni resolver dependencias ajenas.
