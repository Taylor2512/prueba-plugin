# TRC-023 — Schema alias normalization policy

## Objective

Normalize legacy aliases on import while exporting canonical type names only.

## Policy

- canonical type: select
- legacy alias: dropdown
- import: alias -> canonical
- export: always canonical

## Acceptance

- alias map authority is explicit and tested;
- legacy imports remain compatible;
- new exports never emit deprecated aliases.

## Safety

No bidirectional alias drift.
