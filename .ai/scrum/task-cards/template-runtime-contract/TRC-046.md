# TRC-046 — Public API for workspace/template operations

## Objective

Expose host-facing API for template/users/documents/assignments/snapshot lifecycle without leaking internal canvas/registry mechanics.

## Target operations

create instance, get/set template, users, documents, assignments, export/import template, get/restore snapshot.

## Acceptance

- API signatures are consumer-agnostic and typed;
- internals remain encapsulated;
- compatibility tests protect host integration path.

## Safety

No deep imports from UI internals in public API.
