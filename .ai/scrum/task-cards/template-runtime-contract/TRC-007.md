# TRC-007 — normalizeUsers/indexUsers/validateUsers authority

## Objective

Create a single authority pipeline for user normalization, indexing and validation.

## Required behavior

- duplicate id -> error
- empty id -> error
- duplicate email -> warning/policy
- invalid activeUserId -> fail closed
- missing displayName -> controlled fallback
- non JSON-safe metadata -> reject

## Acceptance

- one pipeline function set used by import/restore/runtime initialization;
- deterministic behavior and structured issues;
- no identity fallback from array order.

## Safety

Reject functions, Blob/File and cyclic objects in user metadata.
