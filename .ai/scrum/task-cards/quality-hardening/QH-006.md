# QH-006 — Sibling isolation con assertions inmediatas

## Objetivo

Separar fallo de primera escritura de rollback entre siblings.

## Trabajo

- Después de cada `escribirValor`, afirmar el campo editado inmediatamente.
- Sólo después ejecutar la aserción transversal de valores previos.
- Clasificar `FIRST_EDIT_DID_NOT_COMMIT` antes de hablar de rollback.
- Repetir 20 ediciones con trace en fallo.

## DoD

El spec identifica si falla input/harness, commit inmediato o rollback real.
