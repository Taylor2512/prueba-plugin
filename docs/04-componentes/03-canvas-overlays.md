# Canvas y overlays

## Canvas

Debe preservar:

- PDF background.
- Coordenadas.
- Zoom.
- Scroll.
- Paper geometry.
- Active document.
- Active page.

## Overlays

Pueden incluir:

- Toolbar contextual.
- Inline edit.
- Metrics.
- Comments.
- Context menu.
- Snap feedback.
- Drop placeholder.

## Regla

Ningún overlay debe romper selección, drag, resize o scroll.
