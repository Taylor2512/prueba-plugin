# TRC-006 — Canonical Users registry contract

## Objective

Formalize SisadPdfmeUser as consumer-agnostic identity authority mapped from host participants.

## Target shape

- id
- displayName
- email?
- initials?
- color?
- avatarUrl?
- metadata?: Record<string, JsonValue>

## Acceptance

- no business routing fields leak into core user identity;
- host adapter mapping is explicit and tested;
- runtime multi-user isolation keeps activeUserId canonical;
- JSON-safe metadata policy is enforced.

## Required process

1. characterize existing user model sources;
2. define canonical type and validation boundaries;
3. add adapter tests from legacy/host participant shapes;
4. link with assignments and signatures contracts.

## Safety

Do not serialize host credentials, tokens or runtime-only state.
