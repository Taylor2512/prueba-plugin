# Checklist — Diseño tipo editor profesional

- [ ] No se copió marca/CSS propietario.
- [ ] PDF sigue siendo protagonista.
- [ ] Schemas idle son ligeros.
- [ ] Selected no es agresivo.
- [ ] Toolbar no tapa contenido crítico.
- [ ] Groups tienen borde punteado y `+` integrado.
- [ ] Labels técnicos están ocultos en vista principal.
- [ ] DetailView es compacto y específico por tipo.
