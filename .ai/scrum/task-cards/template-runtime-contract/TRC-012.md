# TRC-012 — Canonical Document registry contract

## Objective

Formalize stable document resource identity and validation contract.

## Target shape

- id
- name
- order
- pageCount?
- sourceRef?
- metadata?: Record<string, JsonValue>

## Acceptance

- no identity from filename;
- duplicate documentId and duplicate order are validated;
- schema.documentId and activeDocumentId references validated fail-closed;
- invalid pageIndex against pageCount surfaced as structured issue.

## Evidence requirements

- validator tests for duplicate/orphan/page bounds;
- import preflight diagnostics include document-level path/entity IDs.

## Safety

Do not serialize non-portable file handles or host credentials.
