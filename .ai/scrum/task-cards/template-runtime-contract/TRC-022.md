# TRC-022 — Complete group schema identity contract

## Objective

Stabilize group schema persistence and identity across duplicate/undo/export/import paths.

## Required identity coverage

group schema ID, group UID, option IDs, option ordering, defaults, assignment, readOnly, positionLocked.

## Acceptance

- duplicate group behavior is explicit for schemaUid/optionId regeneration;
- undo/redo preserves coherent identity;
- export/import preserves durable group identity semantics.

## Evidence requirements

- contract tests for checkbox/radio group duplication and restore;
- regression tests against previous identity loss cases.

## Safety

Do not infer option identity from label order.
