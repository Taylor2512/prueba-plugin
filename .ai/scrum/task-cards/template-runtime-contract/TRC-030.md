# TRC-030 — Designer import/export UI with preflight summary

## Objective

Expose template import/export flows with explicit preflight summary before replacing active workspace.

## Required summary

documents, users, schemas, assignments, warnings, migrations.

## Acceptance

- import confirmation blocks replace until preflight passes;
- migration/warning counts are visible and accessible;
- cancel path leaves workspace untouched.

## Safety

No blind replace from uploaded JSON.
