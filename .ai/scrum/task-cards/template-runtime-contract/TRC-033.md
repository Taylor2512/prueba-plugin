# TRC-033 — Single command registry authority for shortcuts

## Objective

Derive keyboard, menu labels, help panel, accessibility and enabled-state from one DesignerCommandRegistry authority.

## Acceptance

- no command/action drift between shortcut and menu entries;
- parity tests protect lock-position/readOnly aliases;
- command metadata drives docs/help entries.

## Safety

No duplicate hardcoded action maps in UI surfaces.
