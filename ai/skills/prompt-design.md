# Prompt Design

## Propósito

Crear prompts ejecutables y cortos.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Definir rol.
2. Copiar objetivo.
3. Listar lectura.
4. Definir límites.
5. Definir entrega.
6. Definir parada.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No duplicar toda la arquitectura.

## Salida

```md
## Alcance
## Evidencia
## Procedimiento aplicado
## Resultado
## Riesgos
## Dependencias
```
