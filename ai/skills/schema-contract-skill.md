# Schema Contract Skill

## Propósito
Cubrir ciclo completo de schema.

## Cuándo usar
Nuevos tipos o regresiones.

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento
1. Definir metadata.
2. Registrar familia.
3. UI/PDF render.
4. Value adapter.
5. Inspector.
6. Probar runtime/generator/snapshot.

## Validaciones
Owner, docs y UID preservados.

## Anti-patrones
Agregar solo renderer.

## Salida
```md
## Alcance
## Evidencia
## Cambios
## Validación
## Riesgos
## Dependencia
```
