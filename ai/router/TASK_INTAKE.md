# Intake

## Preguntas

- ¿Cuál es el síntoma?
- ¿Qué test lo reproduce?
- ¿Qué contrato se espera?
- ¿Quién es owner?
- ¿Qué proveedor?
- ¿Qué paths están permitidos/prohibidos?
- ¿Existe task previa?
- ¿Es actual, externa o histórica?
- ¿Requiere archivo transversal?
- ¿Requiere gate?

## Rechazo

No iniciar con carpeta incorrecta, ownership ambiguo, colisión, scope >5 archivos, propuesta de parche a expected, node_modules o wrapper muerto.

Separar por causa raíz:

```txt
scroll ≠ densidad ≠ persistencia ≠ focus
```
