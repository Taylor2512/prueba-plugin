# QH-019 — Edición de siblings, contenteditable y tipos de entrada

- Capturar snapshot inmediatamente después de cada edición; distinguir `FIRST_EDIT_DID_NOT_COMMIT` de `SIBLING_ROLLBACK`.
- Helper de texto debe usar `contenteditable="plaintext-only"`, seleccionar contenido sin asumir `input.value` y disparar el evento que consume el editor.
- Number debe usar teclado/semántica de número y validar decimal, negativo, vacío y locale sin convertir `42` en string accidental.
- Probar siblings en páginas distintas, undo/redo, autosave y colaboración para confirmar que una mutation no reemplaza el array completo.
