# Moveable / Selecto Rules

## Targets válidos

```txt
.sisad-pdfme-ui-custom-selectable[data-schema-id]
```

## Excluir

```txt
[data-option-id]
[data-role="group-add-option"]
.moveable-control
.moveable-line
.moveable-control-box
input
textarea
[contenteditable="true"]
toolbar
popover
modal
```

Moveable transforma solo roots.
