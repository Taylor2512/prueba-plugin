# TRC-004 — Separate schema technical identity from visible name

## Objective

Enforce durable schema identity independent from UI labels, ordering and visual accents.

## Required fields

- schemaUid
- type
- name
- displayLabel
- documentId
- pageIndex
- position
- size
- rotation
- readOnly
- positionLocked
- hidden
- required

## Acceptance

- schemaUid is the only durable identity key;
- validators reject duplicate schemaUid and invalid references;
- label/name/order/color are never used as identity;
- migration path for legacy items without schemaUid is explicit.

## Required process

1. characterize current identity authority and weak points;
2. patch validators and normalization;
3. add contract tests for duplicates/orphans/invalid page/type;
4. wire trace to assignment/snapshot/import pipelines.

## Safety

No identity from array index or DOM order.
