# Regeneration

Generated context packs are navigation artifacts.

After a verified SISAD-PDFME change:
1. run focal/full gates required by the task;
2. regenerate SISAD-PDFME code/docs/styles packs from this repository only;
3. rebuild indexes;
4. validate links/stable names;
5. attach HEAD/source hashes to evidence.

Do not import external-project documentation into SISAD-PDFME Brain.
