# Guía IA: arquitectura del asistente

## Qué debe hacer el asistente

- Entender el dominio.
- Elegir agente.
- Cargar skill.
- Ejecutar prompt.
- Proponer cambios pequeños.
- Validar con tests.
- Actualizar docs.

## Qué no debe hacer

- Refactors masivos sin plan.
- Mezclar flujos externos.
- Duplicar componentes.
- Romper snapshot.
- Crear CSS global invasivo.
