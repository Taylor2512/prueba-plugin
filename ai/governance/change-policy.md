# Política de cambios

## Tipos

```txt
bugfix
feature
refactor
visual
documentation
performance
security
migration
```

Una entrega debe declarar un tipo principal.

## Reglas

- Un bugfix no contiene rediseño amplio.
- Un cambio visual no modifica contratos.
- Un refactor no altera comportamiento.
- Una migración incluye compatibilidad.
- Un cambio de seguridad tiene prioridad sobre polish.
