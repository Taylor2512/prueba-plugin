# SISAD PDFME — Arquitectura IA v5

Este paquete contiene la arquitectura Markdown para coordinación multi-proveedor de IA en `sisad-pdfme`.

## Objetivo v5

Pasar de fixes locales a contratos por proceso para evitar regresiones.

## Incluye

- Router IA neutral.
- Agentes, reglas, contextos, prompts y skills.
- Contrato maestro de comportamiento.
- Metodología por proceso.
- Patrones UX inspirados en DocuSign/Wix sin copiar marca.
- Casos de uso de todos los schemas estándar.
- Matrices de pruebas unitarias y Playwright.
- Instrucciones para completar faltantes.

## Arranque rápido

Usa `START_PROMPT.md` para cambios normales y `START_PROMPT_BEHAVIOR_AUDIT.md` para auditorías/regresiones.
