# Interaction Regression

## Objetivo

Ejecutar un procedimiento repetible dentro de una task-card.

## Precondiciones

- tarea activa;
- ownership claro;
- contexto focal;
- reglas cargadas;
- evidencia inicial.

## Procedimiento

1. Trazar evento.
2. Revisar guards.
3. Revisar locks.
4. Corregir lifecycle.
5. Restaurar foco.
6. Documentar.

## Salida

- causa raíz;
- cambios;
- contratos;
- evidencia;
- riesgos;
- handoff.

## Parada

No ampliar el dominio ni resolver dependencias ajenas.
