# TRC-010 — Persist positionLocked independently from readOnly

## Objective

Guarantee independent persistence and runtime behavior for positionLocked and readOnly combinations.

## Required combinations

1. positionLocked=false, readOnly=false
2. positionLocked=true, readOnly=false
3. positionLocked=false, readOnly=true
4. positionLocked=true, readOnly=true

## Acceptance

- all four combinations survive Designer -> export -> import -> Designer -> Form -> Viewer;
- move/resize/delete blocking follows positionLocked contract only;
- value editability follows readOnly/surface policy only;
- no conflation in serializer or runtime resolver.

## Evidence requirements

- table-driven unit tests for persistence map;
- E2E scenario per combination;
- snapshot round-trip assertions with semantic compare.

## Safety

Do not infer lock state from UI icon composition.
