# TRC-038 — Reload/import lock state parity

## Objective

Prove lock durability through export/import/reload and runtime surfaces.

## Acceptance

- readOnly and positionLocked survive export/import exactly;
- Form and Viewer consume restored lock state correctly;
- mismatch scenarios emit diagnostic evidence.

## Evidence requirements

- E2E scenario: set -> export -> reload/import -> assert -> Form/Viewer assert.

## Safety

No PASS without post-reload assertions.
