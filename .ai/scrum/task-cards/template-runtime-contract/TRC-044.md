# TRC-044 — Template JSON contract test matrix

## Objective

Implement exhaustive contract tests for valid, invalid and migration cases.

## Minimum matrix

minimal valid, full valid, unknown field policy, duplicate user/document/schema, orphan assignment, unknown type, legacy alias, invalid page/geometry/optionId/signature, non JSON-safe metadata, malformed JSON, unsupported schemaVersion.

## Acceptance

- each case maps to structured issue code/severity;
- unsupported/invalid are fail-closed;
- migration-accepted cases are explicitly tagged MIGRATED.

## Safety

No catch-all generic error without path/entity context.
