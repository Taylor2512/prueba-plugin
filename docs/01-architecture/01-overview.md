# Overview — PDF Designer

El diseñador PDF de SISAD PDFME es un runtime visual para ubicar y configurar schemas sobre documentos PDF.

## Componentes

- Designer;
- Canvas;
- Paper;
- Renderer;
- Schemas;
- LeftSidebar;
- RightSidebar;
- DetailView;
- ListView;
- Toolbar contextual;
- Moveable;
- Selecto;
- CommandBus;
- Snapshot.

## No incluye

Flujos de negocio externos ni firma backend.
