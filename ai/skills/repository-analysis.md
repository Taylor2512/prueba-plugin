# Repository Analysis

## Propósito

Analizar repositorios grandes sin lectura indiscriminada.

## Cuándo usar

Cuando una task-card declare esta capacidad como necesaria.

## Entradas

- objetivo;
- contexto focal;
- reglas;
- archivos;
- evidencia.

## Procedimiento

1. Definir preguntas.
2. Mapear módulos.
3. Muestrear símbolos.
4. Identificar fronteras.
5. Clasificar hallazgos.
6. Proponer tareas.

## Validaciones

- alcance respetado;
- causa raíz explícita;
- contrato preservado;
- dependencia documentada;
- salida reproducible.

## Anti-patrones

No leer todo ni generar listas sin prioridad.

## Salida

```md
## Alcance
## Evidencia
## Procedimiento aplicado
## Resultado
## Riesgos
## Dependencias
```
