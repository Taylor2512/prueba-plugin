# Host Adapter Skill

## Propósito
Mapear datos host a contratos.

## Cuándo usar

## Entradas
- Task-card.
- Contexto focal.
- Rules.
- Archivos y tests.

## Procedimiento

2. Sin APIs.
3. Preservar IDs.
4. Metadata opcional.
5. Entradas incompletas.
6. Fallback.

## Validaciones
Core no conoce host.

## Anti-patrones
