# Markdown Governance

## Reglas

- Un Markdown = una responsabilidad.
- No duplicar prompts por proveedor.
- No guardar logs extensos.
- No meter código fuente consolidado dentro de docs permanentes.
- No crear matrices gigantes si basta checklist focalizada.
- Actualizar memoria al cierre.

## Tamaños recomendados

| Tipo | Máximo |
|---|---:|
| memoria | 150 líneas |
| regla | 120 líneas |
| contexto | 200 líneas |
| prompt | 250 líneas |
