# Application Behavior Contract

## Proceso base

```txt
Proceso -> Componentes -> Fuente de verdad -> Estados válidos -> Datos preservados -> Validaciones -> Implementación
```

## Procesos

Crear schema, seleccionar, mover, redimensionar, rotar, selección múltiple, agregar opción, cambiar destinatario, snapshot, externalForms, Form/Viewer/Generator, firma, no-overlap y multipágina.

## Datos preservados

`schemaUid`, `type`, `documentId`, `pageNumber/pageIndex`, geometría, owner/color, required/readOnly, dataLabel, value, groupId, optionId y selected values.
