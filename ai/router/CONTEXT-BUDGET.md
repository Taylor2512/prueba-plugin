# Presupuesto de contexto

## Carga base

```txt
START
task-card
current-state
decisions
known-risks
contexto focal
rules focales
playbook
archivos autorizados
```

## Límites

- 1 task-card.
- 1–2 contextos.
- 1–2 rules.
- 1 playbook.
- 2 búsquedas globales.
- 8 archivos fuente.

## No cargar por defecto

- archive;
- reports históricos;
- tasks completed individuales;
- conversaciones;
- outputs generados;
- documentación externa no relacionada.
