# SKILL — Contrato maestro de comportamiento

## Cuándo usar

Cuando una corrección afecta varias capas o causa regresiones nuevas.

## Pasos

1. Identificar proceso.
2. Mapear componentes.
3. Declarar fuente de verdad.
4. Crear matriz de estados válidos/inválidos.
5. Exigir tests.

## No hacer

No corregir por síntoma. No saltar diagnóstico.

## Validación

Matriz de proceso actualizada y tests focalizados.
