# Text y Number — contrato

## Text

Debe soportar contenido, placeholder, required, readonly, maxLength, multiline opcional, estilo de fuente, owner, color, snapshot y PDF.

## Number

Debe soportar value/defaultValue, min/max, decimals, format, required, readonly, owner, color, snapshot y PDF.

## No negociable

- No perder `schemaUid` al editar.
- No mezclar ownerColor con activeRecipientColor.
- No ejecutar shortcuts mientras se edita input.
- DetailView debe cubrir cada propiedad.
